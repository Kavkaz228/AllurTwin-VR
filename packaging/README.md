# Переносимая Windows-сборка

Сначала выполните установку зависимостей и сборку Unity из корневой инструкции. Сборщик запускается под Windows с Python, содержащим стандартную библиотеку, и Node.js в PATH.

Укажите каталоги установленной Ollama и скачанных моделей:

```powershell
$env:ALLUR_OLLAMA_RUNTIME = 'C:\path\to\ollama'
$env:ALLUR_OLLAMA_MODELS = 'C:\path\to\models'
python packaging/build_portable.py
```

Каталог runtime должен содержать `ollama.exe` и необходимые ему библиотеки. Каталог моделей — `manifests` и `blobs`, включая `qwen3:4b`. Используется `.venv/Lib/site-packages`, созданный установочным скриптом. Для компиляции лаунчера нужен .NET Framework C# compiler, используемый скриптом.

Результат: `release/v1.1/AllurTwin-VR`. Проверяйте готовую поставку на чистой Windows перед распространением. Лаунчер — `AllurTwin.exe`; не перемещайте его отдельно от остальных файлов. Пользователь распаковывает весь архив и запускает этот файл.

Веса моделей, runtime, пароли и пользовательские базы не добавляются в Git. Сборщик сохраняет лицензии компонентов.
